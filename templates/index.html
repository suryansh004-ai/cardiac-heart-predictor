How the Prediction Pipeline Works

A robust 4-step classification pipeline replicating real-world machine learning deployment practices.

1

Enter Health Metrics

Input 13 medical indicators including blood pressure, cholesterol, resting ECG, and treadmill exercise test markers.

2

Standardized Scaling

Numerical features are normalized using StandardScaler fitted strictly on the training set to prevent data leakage.

3

Model Inference

A calibrated Logistic Regression model calculates the decision boundary and outputs the class probability.

4

Risk Likelihood & Insights

The system displays the predicted risk category, confidence percentage, and highlights contributing clinical factors.
